# 交互式构建使用指南

## 启动交互式构建

```bash
yarn build
```

## 界面说明

### 1. 启动界面

启动后，会显示：

```
============================================================
    图标字体构建工具 - 交互模式
============================================================

ℹ 扫描到 1 个图标包:
  有文件: 1 个
  空包: 0 个
```

### 2. 包详情

显示每个包的状态：

```
包详情:

  📦 untitled
     描述: 图标字体库
     图标: 50 个
     新增: 3 个
     修改: 2 个
     原因: 文件内容变化
```

### 3. 构建计划

自动分析哪些包需要构建：

```
============================================================
    构建计划
============================================================

📦 需要构建的图标包 (1 个):

  1. untitled
     原因: 文件内容变化
     变化: 新增 3 个, 修改 2 个

⏭  跳过的图标包 (0 个):

============================================================
```

### 4. 操作菜单

```
请选择构建模式:
  1. 增量构建 (仅构建有变化的包)
  2. 全量构建 (构建所有包)
  3. 选择性构建 (手动选择要构建的包)
  4. 清理缓存并全量构建
  0. 退出

请输入选项 (1/2/3/4/0):
```

## 使用场景

### 场景 1：日常开发（增量构建）

添加了一些新图标后：

1.  运行 `yarn build`
2.  查看变化详情
3.  选择 `1` - 增量构建
4.  系统自动构建有变化的包

### 场景 2：首次构建或大量修改（全量构建）

1.  运行 `yarn build`
2.  选择 `2` - 全量构建
3.  系统构建所有包

### 场景 3：只构建特定的包（选择性构建）

1.  运行 `yarn build`
2.  选择 `3` - 选择性构建
3.  输入包的编号，如 `1` 或 `1,2,3`
4.  系统只构建选中的包

### 场景 4：缓存出问题（清理缓存）

1.  运行 `yarn build`
2.  选择 `4` - 清理缓存并全量构建
3.  确认操作 `y`
4.  系统清理缓存后重新构建所有包

## 快捷键

- 输入数字 `1-4` 选择构建模式
- 输入 `0` 退出程序
- `Ctrl+C` 强制退出

## 提示

1.  **增量构建**是最常用的模式，速度快
2.  **全量构建**用于首次构建或确保所有包都是最新的
3.  **选择性构建**适合只修改了特定包的情况
4.  **清理缓存**用于解决缓存相关问题

## 常见问题

### Q: 显示"无需构建"怎么办？

A: 说明所有包都是最新的。如果确实修改了文件，可以选择"清理缓存并全量构建"。

### Q: 如何查看详细的变化？

A: 在包详情部分会显示新增、修改、删除的图标数量。

### Q: 可以同时构建多个包吗？

A: 可以，在选择性构建中，输入多个编号，用逗号分隔，如 `1,2,3`。

### Q: 交互式构建和命令行构建有什么区别？

A: 交互式构建（`yarn build`）提供可视化界面和更多选项，适合日常开发。命令行构建（`yarn build:cli`）适合脚本和 CI/CD 环境。
